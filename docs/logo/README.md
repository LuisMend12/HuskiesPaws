# HuskiesPaws logo

An original husky character: a navy-and-white palette with icy-blue eyes, in the spirit of a university husky mascot, plus a **blooming paw print** (toe pads as flower petals) for the app's walk-and-bloom idea. It's our own artwork. It doesn't use UConn's or any other school's trademarked logos, so it's safe to use publicly.

| File | Use it for |
|---|---|
| `huskiespaws-logo.png` / `.svg` | README, deck title slide, Devpost (light backgrounds) |
| `huskiespaws-logo-dark.png` / `.svg` | Dark backgrounds and dark-mode slides |
| `huskiespaws-icon-1024.png` | Devpost thumbnail, Expo app icon (`mobile/assets/icon.png`) |
| `huskiespaws-icon-512.png` | Social previews, slide corners |
| `huskiespaws-icon.svg` | Favicon and any size (scalable) |

**Colors:** navy `#0B1F3A`, husky gray `#5B6B82`, ice blue `#6EC6FF`, bloom green `#2E9D4F`, petal pink `#F48FB1`, petal yellow `#FFD54F`.
**Font:** Nunito (Black / ExtraBold, free on Google Fonts).

The PNGs were rendered from the SVGs with Chrome. In the SVGs, the wordmark falls back to a system font where Nunito isn't installed, so use the PNGs when the font matters.
